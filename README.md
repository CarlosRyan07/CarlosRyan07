### **🧪 Quality Assurance**

Atualmente, minha atuação é voltada para qualidade de software, com foco em validação técnica e funcional de aplicações backend.

- Planejamento, execução e documentação de testes funcionais, exploratórios, regressivos e de integração.
- Criação e manutenção de testes automatizados para APIs REST com **Java, JUnit 5, Mockito, MockMvc e Spring Boot Test**.
- Validação de APIs REST, autenticação, autorização, tokens, headers HTTP e contextos multi-tenant.
- Análise de código, logs, banco de dados e consultas SQL para investigação de defeitos.
- Criação e manutenção de massa de testes utilizando **PostgreSQL** e **SQL**.
- Validação de microsserviços, mensageria, processamento assíncrono, migrations, rollbacks e parametrizações.
- Documentação de evidências de testes e registro de bugs com informações técnicas, payloads, logs e passos para reprodução.
